How to read these results

Claude Desktop settings runs Claude Code, which is what Claude Desktop's Code tab runs, with your own setup: your plugins, MCP servers, skills, CLAUDE.md and sign-in. It opens in a window of its own so you can watch it. ClaudeOS runs a chat in the brain you pick, with its team, memory and skills; its window shows that chat live.

Measurements come from each side's own session log: model calls, tools, fresh, cached and output tokens. Compare tokens only between sides of the same model family. Cost weights them by Anthropic's price ratios (a cache read 0.1×, a 5-minute cache write 1.25×, a 1-hour one 2×, output 5×, all relative to one fresh input token), so the two Claude sides compare in one number; it is usage, not money you pay on a subscription. After a round, What they made shows each side's page side by side and the files it made or changed. A test task is also checked in a real browser (behaviour 65, robustness 10, a blind appearance vote 25; the weights are provisional). With more than one round, the medians across rounds are what count; the first side alternates in "one after the other".

Background sessions a contestant starts by itself (ClaudeOS grading or coaching) are not counted.
