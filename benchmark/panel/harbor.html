Lab benchmark

The method professional AI labs use (Harbor, the Terminal-Bench harness): ClaudeOS and plain Claude Code (what Claude Desktop runs) each do the same task several times, every attempt in a fresh container with the same model and effort. The results are checked automatically. Side-by-side benchmark

Runs use your Claude subscription sign-in, never an API key. They count toward your plan's usage limits, so they run one at a time.

How to read the results

Solved: every gate passes (the page loads, has the required hooks, no console errors, no external requests) and all behaviour tests pass in a real browser. Score: behaviour tests (65) and robustness checks (10), out of 100; the appearance judge isn't part of the lab run.

API-price cost: what the attempt's tokens would cost at Anthropic's API prices, as estimated by Claude Code. You pay nothing extra: this is the fairest single number for comparing efficiency, because cached input is much cheaper than fresh input and output costs most.

Chance ClaudeOS is cheaper / better: how often ClaudeOS comes out ahead when the attempts are resampled 2,000 times (bootstrap). Around 50% means no real difference. Look for 90% or more, and run more attempts if it's close.

The ClaudeOS contestant gets what a ClaudeOS chat adds to Claude Code: the foundations in CLAUDE.md, the runtime context, the brain's instructions and skills, and the shared memory (a copy). ClaudeOS's desk tools (terminal, artifacts, approval cards) aren't in the container.
